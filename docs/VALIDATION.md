> 本文记录《微境：人工生命生态箱》的实际验证过程、复现步骤与结果。所有数值均为真实运行产出，未做修饰。
> 最后更新：2026-11-06（随验收进度持续更新）

| 项目 | 值 |

## 2. 核心因果测试（Vitest，`npm test`）

`tests/causality.test.ts` 共 9 项，全部通过：

1. **进食**：食物被真实消耗（草地生物量下降），动物能量上升，增益 = 咬合量 × 能量密度 × 消化效率。
2. **代谢与移动**：无食物时能量下降；高速基因个体比低速基因个体消耗更多（移动成本 ∝ 速度² × 体型^1.35）。
3. **繁殖成本**：子代出生后亲代能量被扣除（子代能量 × 1.5），进入冷却；子代继承谱系与代次。
4. **捕食不创生**：捕食者获得能量 ≤ 猎物原能量 × 72%；残骸在猎物死亡格生成；系统总能量（个体 + 残骸折算）不增加。
5. **分解**：残骸减少的同时养分增加（无重复结算）。
6. **死亡即终止**：能量归零的个体被移出种群、不产生后代、留下残骸。
7. **光照/水分/养分 → 植物**：白天生长 > 黑夜生长（同一地块对照）。
8. **干预**：播种增加植物、降雨提升水分并写入事件日志；无效干预返回原因；人工投放个体带 `artificial` 标记。
9. **行为状态**：天敌靠近时个体进入逃逸状态。

## 3. 遗传测试（Vitest）

`tests/genetics.test.ts` 共 11 项，全部通过：

- **继承与突变**：500 个子代基因全部在 [0.02, 0.98]；实测突变率与参数（0.35）一致；单基因突变幅度 ≤ 3×jumpSigma。
- **子代来自有效亲代**：`parentId`、`generation+1`、`lineageId` 全部正确。
- **成年基因稳定**：连续 4000 tick，基因快照完全不变（年龄只改变表现型体型比例）。
- **性状 → 成本**：体型↑ → 基础代谢↑ 且能量上限↑；感知↑ → 感知维持成本↑；速度↑ → 移动能耗↑；耐旱↑ → 干旱时总开销↓ 但无干旱时开销↑（明确的收益/代价）。
- **性状 → 行为**：快速捕食者（速度基因 0.95）能捕获慢速猎物；慢速捕食者（0.05）对快速猎物捕获耗时显著更长（micro 对照实验）。
- **繁殖投入**：投入越高，子代起步能量越多、亲代剩余越少。
- **初代基因围绕物种中心分布**：捕食者平均速度基因显著高于食草者。

## 4. 可复现性与存档测试（Vitest）

`tests/repro.test.ts` 共 13 项，全部通过：

- **同种子 + 相同干预序列 → 一致关键状态**（3000 tick，5 次干预后逐字段比对一致）。
- **不同种子 → 不同状态**。
- **存档续推一致**：tick 2500 存档后，"继续推进 1500 步" 与 "恢复存档再推进 1500 步" 的关键状态完全一致。
- **1× 与倍速一致**：1000 次单步 vs 100 轮 × 10 步到达同一 tick，状态一致（排除渲染帧率等无关字段）。
- **干预在确定 tick 生效**：相同 tick 的干预序列可复现。
- **存档校验**：拒绝错误格式/错误版本/数组长度不符/NaN/越界基因/重复 ID/未知挑战引用；JSON 解析失败与过大文件（>64MB）有明确错误。
- **JSON 往返**：序列化 → 解析 → 恢复 → 推进，与原连续推进一致。
- **挑战存档**：带 `challenge` 状态，可恢复。

> 开发过程中通过这些测试发现并修复了 4 个真实 bug：`toSaveData()` 误消耗全局 ID 计数器、`decisionTimer` 未序列化、`targetRef` 未恢复、`fromSave` 漏初始化 `counters`。ID 分配已重构为每个 Simulation 独立序列。

## 6. 三关挑战验证（`scripts/challenge-check.ts`）

每关均验证：**无干预路径、合理干预路径（反应式玩家）、错误策略路径**。反应式玩家每 200 tick 评估一次种群状态并使用干预（与真人玩家行为一致）。

| 关卡 | 无干预 | 合理干预（反应式玩家） | 错误策略 |
| --- | --- | --- | --- |
| A · 生态守护 | ❌ 超时未持续达标 | ✅ **成功 @20,512 tick（约 5.7 分钟 @1×）** | ❌ 捕食者灭绝 @20,316 |
| B · 旱季之后 | ✅ 恢复 @12,067 | ✅ 成功 @11,771 | ❌ 连续 8 次触发干旱 → 捕食者灭绝（无头 @7,198；浏览器实测 @8,247） |
| C · 谱系延续 | ✅ 自然繁衍 @18,372 | ✅ 成功 @16,914（均约 5 分钟） | ❌ 连续投放 5 只捕食者压制 → 超时未达标（浏览器实测 @30,001） |

参数已在验收前冻结于 `src/sim/config.ts` 的 `CHALLENGES`（A：小食草≥150/大食草≥100/捕食者≥8/植物≥180,000 持续 60 秒，8 次干预，7.5 分钟时限；B：干旱谷地预设，900 tick 后 50 秒干旱，恢复后持续达标 30 秒，10 次干预；C：创始群体 6 只，7 代 / 100 个自然后代，中期干旱，5 次干预）。

**失败→结算→重试链路已在浏览器实测**（守护关）：连续触发干旱 → 捕食者灭绝 → 失败结算弹窗（显示失败原因）→ 点击"重试挑战" → 干预配额恢复为 8、种群重置、tick 归零，挑战重新开始。

## 7. 性能基准

### 7.1 模拟核心（Node 无头，`scripts/bench.ts`，Apple M4 / Node 24）

| 场景 | 实测 |
| --- | --- |
| 400 生物（128×80 地形） | 0.37–0.44 ms/tick（≈2,300–2,700 tick/s 理论上限） |
| 1,000 生物高密度 | 0.69 ms/tick（峰值段） |
| 默认预设初始种群 | 0.18–0.56 ms/tick |

### 7.2 浏览器端（ego-lite / Chromium / Apple M4 / ANGLE-Metal 硬件 WebGL / PixiJS 8.22）

| 场景 | 实测 |
| --- | --- |
| 411 生物 @1440×900 @1×（25 秒平均） | **28.8 FPS**（= 浏览器 rAF 上限，见下），实际推进 61.5 tick/s，模拟耗时 0.70 ms/tick |
| 969 生物 @2189×1111 @dpr2 @5× | 28 FPS，306 tick/s，0.42 ms/tick |
| 浏览器原始 rAF 上限（无游戏负载） | 帧间隔中位数 34.7ms ≈ **28.8 FPS** |

**结论**：自动化浏览器对未聚焦窗口的 rAF 节流到 ~29 FPS，游戏用满了浏览器提供的每一帧（模拟仅占 16.7ms 预算的 4%）。在正常聚焦的浏览器窗口中 rAF 为 60Hz，按 0.7ms/tick 的模拟成本可达到 60 FPS；本环境无法直接测出 >29 FPS 的数字，此处如实说明，不用虚拟环境数据冒充。

### 7.3 10 分钟连续运行（soak）

- 场景：沙盒世界（种子 777001），5× 速度连续运行约 10 分钟，期间切换叠加层、切换面板、进行干预、多次保存。
- 结果：推进 81,555 tick（251 → 81,806），峰值约 970 个体；FPS 稳定 28–29（rAF 上限），模拟 0.38–0.42 ms/tick；自动存档（tick 81,000）与手动槽位保存均正常；无未处理错误、无容量警告、无卡死。

## 8. 浏览器完整操作验收（ego-browser 实测）

按正式构建（`npm run build` + `vite preview`）逐项通过：

1. 启动 → 主菜单（标题/插画/七个入口/存档列表/挑战卡）。
2. 创建世界（自定义种子 + 预设）→ 场景渲染（地形/植被/生物/昼夜）。
3. 暂停 → tick/s 归零；单步 3 次；1×/2×/5×/10× 切换，实际推进速度诚实显示（5× 实测 211–319 tick/s）。
4. 缩放（滚轮 61%→93%）、拖动平移、点击选中个体（选中后面板更新）。
5. 个体面板：能量/年龄/状态与行为原因/六项基因（数值+收益代价）/表现型/亲代/谱系/代数（实测出现第 6–10 代个体）。
6. 环境干预：降雨（事件日志记录"人工降雨（持续 15 秒）"）、地形笔、播种；挑战中干预配额正确扣减（8→7）。
7. 数据面板：种群曲线、死因分布、性状分布（p10–p90）、事件日志（出生/灭绝/死亡/干预）。
8. 谱系面板：三代追溯与谱系汇总。
9. 保存到槽位 → 刷新页面 → 从菜单载入 → 世界恢复继续。
10. 导出世界 JSON（约 935KB，含地形/全部个体/谱系/档案/事件/挑战状态）。
11. 导入有效文件 → 世界恢复（跨会话续玩）。
12. **无效导入保护**：损坏 JSON 与错误格式文件都被拒绝并显示明确原因，当前世界不被破坏。
13. 挑战流程：简报 → 开始 → 目标进度/干预配额 → 干预 → 成功结算（自然恢复持续达标）与失败结算（连续干旱 → 捕食者灭绝 @8,247）→ 重试后状态完整重置（干预回 8、种群重置、tick 归零）。

截图见 `screenshots/` 目录（01–24，含主菜单、运行世界、个体面板、谱系视图、数据面板、挑战简报/运行/进度/失败/重试、存档界面、导入导出、引导、帮助、设置、性能测试）。
