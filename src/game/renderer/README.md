# 渲染架构

世界空间分层：地形层（32px/块，离屏整图 Sprite，五地形+水域沙滩过渡）→ 植物层（8px/块，脏单元格重绘：青草/浆果/残骸）→ 数据叠加层（1px/块 ImageData：植被/水分/养分/活动/种群/残骸）→ 生物精灵池（1400 个，图集 4 物种×3 感知档×2 腹部档×6 帧）→ 特效对象池 → 画笔预览；夜色层在屏幕空间，随 light 由暖色渐变至 PALETTE.night。基因→外观：size→缩放、speed→色相、sense→附肢 3 档、reproInvest→腹部斑块；协议未携带基因时按 id 稳定哈希分档。公开 API 用瓦片单位（同快照），相机内部用世界像素。全程 `scaleMode:'nearest'`；WebGL 初始化失败自动回退 Canvas2D（`fallback2d`），保留地形+圆点生物+选中标记，保证可玩。
