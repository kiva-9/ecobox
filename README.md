# 微境：人工生命生态箱（EcoBox）

一款本地运行的单机 2D 人工生命生态模拟游戏。你创造一片小世界，观察生物觅食、逃跑、捕猎、繁殖、死亡，见证后代的性状在自然选择下慢慢改变；你可以改变环境、保护一条谱系、收藏并重新投放喜欢的个体。

- **中文界面 / 精致俯视角像素风**：32×32 地形块、最近邻缩放、程序化生成的原创素材
- **真实的生态因果链**：光照×水分×养分 → 植物生长；进食 → 能量；代谢/移动/感知/繁殖 → 耗能；捕食 → 部分能量转移 + 残骸；残骸 → 食腐或分解 → 养分
- **六项可遗传基因**（速度/体型/感知/耐旱/繁殖投入/胆量），每项都有明确收益与代价，并映射到场景中的外观（体型、色相花纹、附肢长度、腹部斑块）
- **四类动物 + 两类植物 + 三种环境区域**：小型食草者、大型食草者、捕食者、食腐者；青草与浆果灌丛；湿润草地、林地、干旱地（另有水域与岩石作为边界）
- **三关完整挑战**：生态守护、旱季之后、谱系延续（均可开始、完成或失败、结算与重试）
- **Web Worker 模拟 + IndexedDB 存档 + JSON 导入导出**：固定时间步、种子随机数可复现、倍速不改变生态规则

## 在线游玩

**https://kiva-9.github.io/ecobox/** （GitHub Pages 自动部署，推送 main 即更新）

首次打开后可直接创建世界开始游玩；存档保存在浏览器本地（IndexedDB）。

## 快速开始

```bash
npm install     # 安装依赖（需要 Node >= 20.19）
npm run dev     # 开发模式，默认 http://127.0.0.1:5173
```

生产构建与本地预览：

```bash
npm run build   # 类型检查 + 正式构建到 dist/
npm run preview # 本地静态预览，默认 http://127.0.0.1:4173
```

首次安装依赖后，断开外网、仅保留本地服务，核心游戏仍可完整运行（无远端服务、无账号、无大模型依赖）。

## 五分钟上手

1. **创建世界**：主菜单点“开始新世界”，输入种子（或随机）并选择预设（温带河谷 / 湿润草甸 / 干旱谷地）。
2. **观察**：点击场景中的任何生物，右侧“个体”面板会显示它的能量、年龄、状态与**行为原因**（例如“发现捕食者（2.3 格外），正在逃离”）、六项基因与谱系。
3. **干预**：底部工具栏选择工具——地形笔、播种/种植、降雨、触发干旱、投放生物；在场景中点击或拖动即可生效。每次干预都会写入事件日志。
4. **加速与叠加层**：空格暂停/继续，`1`~`4` 切换 1×/2×/5×/10×；工具栏可切换植被/水分/养分/活动/种群/残骸叠加层。
5. **保存与继续**：“世界”面板可保存到自动存档或 3 个手动槽；也可导出 JSON 文件，之后在任意设备上导入继续。

更多玩法（挑战、生命档案、谱系追溯、快捷键）见游戏内“帮助”。

## 玩法要点

- **能量就是一切**：生物每 tick 都要支付基础代谢，移动按速度平方耗能，感知范围有维持成本。找不到食物就会饿死。
- **死亡即选择**：没有“适应度评分”，活得久、后代多就是胜利。六项基因直接改变移动速度、体型、感知半径、耐旱表现、繁殖投入与胆量，并在繁衍中遗传与有限突变。
- **体型有代价**：更大的体型能量储备更高，但基础代谢按体型^1.35 上升；更快的移动让你更容易追上猎物，也更容易甩开天敌，但追逐更耗能。
- **捕食者会冲刺、食腐者会跟随**：捕食者以 1.3 倍速冲刺追猎，得手后会啃食自己的猎物；食腐者嗅觉范围大，会跟随捕食者或食草群，长期找不到食物时进入休眠节省能量。
- **人工投放不计自然繁殖**：挑战“谱系延续”中，只有自然繁殖的后代才计入目标。

## 技术架构

```
src/
  sim/        纯 TypeScript 模拟核心（无 DOM 依赖，可在 Node 直接运行）
    rng / config / constants / types     种子随机数、全部可调参数、枚举、基因定义
    world / spatial / creature / ai      地形与资源场、空间哈希、个体、效用评分 AI
    systems / simulation / challenges    土壤与植物、编排器、三关挑战
    serialize                            存档校验（格式/版本/数值范围/容量）
  worker/     Dedicated Web Worker：固定 60Hz 循环推进模拟，IndexedDB 持久化
  game/       客户端胶水层（Worker 消息、React 状态节流）、像素风渲染器、程序化音效
  ui/         React 界面（菜单、工具栏、五个数据面板、十类弹窗）
  shared/     共享协议（Worker 消息、快照、存档结构、调色板）
```

- **模拟与渲染分离**：模拟在 Worker 中以固定时间步运行（1× = 60 tick/s），倍速 = 每帧推进更多步；UI 通过有界频率的快照读取状态（React 面板约 4Hz，PixiJS 场景每帧）。
- **可复现**：一切影响模拟的随机都来自种子随机数（sfc32）；同一程序版本 + 同一种子 + 相同干预序列 → 完全相同的演化。存档包含随机数状态与全部个体，恢复后可精确续推。
- **性能**：空间哈希邻域查询（无全体两两扫描）、土壤错峰更新（每格每 8 tick 一次）、快照节流与对象池。

## 已知限制

- 食腐者在部分种子的超长跑（>2 万 tick）中最终灭绝——它们是机会主义 niche，早期食物稀少；不影响“植物→食草→捕食者”的基本食物链。
- 移动端未做专属操作优化（桌面浏览器优先，支持 1280×800 / 1920×1080 / 超宽窗口）。
- 繁殖为单亲无性繁殖（游戏内帮助中有说明）。
